# 出世ゲーム

スイカゲーム型の落ちものパズル。同じ役職のキャラクター同士がぶつかると、ひとつ上の役職へ出世する。
インターンから始めて社長を目指す。

公開URL: https://game.chozo.net/shusse-game/

外部ライブラリの読み込みも音声・画像の外部依存もなく、ビルドせずに `file://` のまま動く。

```bash
open index.html
```

ローカルサーバで開くなら `python3 -m http.server 8000` 。

## 遊び方

| 操作 | 内容 |
|---|---|
| ドラッグ / マウス移動 | 落下位置を決める |
| クリック・タップ / Space・Enter | 落とす |
| ← → | 落下位置を微調整 |
| Space・Enter（トップ／ゲームオーバー時） | ゲーム開始 |
| M / 画面下のボタン | 音のオン・オフ |
| H | 当たり判定の表示切り替え（デバッグ用） |

### ルール

- 落ちてくるのは **インターン〜課長** の4種類のみ。出現比率は 40 / 30 / 20 / 10 %
- 同じ役職どうしが接触すると次の役職へ出世する。**社長が最終**で、社長どうしは両方消えて +100 点
- 出世スコアは `k(k+1)/2`（k = 出世後の番号）。0.9 秒以内の連続出世で最大 3.0 倍の連鎖ボーナス
- 着地済みのオブジェクトがデッドラインを **1 秒間** 超え続けるとゲームオーバー
  （落下直後 1.2 秒、出世直後 0.4 秒は判定対象外）
- ハイスコアは端末内（localStorage）に保存される

### 役職

| 001 | 002 | 003 | 004 | 005 | 006 | 007 | 008 | 009 | 010 | 011 |
|---|---|---|---|---|---|---|---|---|---|---|
| インターン | 平社員 | 係長 | 課長 | 次長 | 部長 | 事業部長 | 執行役員 | 取締役 | 副社長 | 社長 |

名称は `js/config.js` の `titles`（添字 = ステージ番号 - 1）。
落下待機中はイラストの足元に役職名のプレートを出し、出世時は出世後の役職名を大きく、
加算点をその下に小さく表示する。

### 画面の流れ

```
トップ画面 ──[ゲーム開始]──▶ ゲーム画面 ──▶ ゲームオーバー ──[もう一度]──▶ ゲーム画面
     ▲                                              │
     └─────────────────[トップに戻る]────────────────┘
```

トップ画面には全11役職を矢印でつないだ進化図を **4 + 4 + 3 の3段** で表示する。
落下対象の4役職は名前を濃く、最終形の社長は金色で示す。
矢印は独立した要素ではなく `li + li::before` で出しているので、折り返しても行末に矢印が残らない。

BGM は「ゲーム開始」を押したときに鳴り始め、ゲームオーバーとトップに戻ったところで止まる。

## URL パラメータ

### `?p=001`〜`?p=011` — 撮影モード

紹介動画の撮影用に、落ちてくる役職を1種類に固定する。

```
https://game.chozo.net/shusse-game/?p=011    社長だけが落ちてくる
```

- `001`〜`011` の3桁表記でも `1`〜`11` でも可。範囲外・不正な値は無視して通常の抽選に戻る
- 指定中はトップ画面にだけ「撮影モード」の表示が出る。**ゲーム画面には出ない**ので動画に映り込まない
- 大きい役職を指定した場合、待機中のイラストが画面上端からはみ出さないよう待機位置を自動で下げる
  （通常の落下対象 001〜004 では位置は変わらない）

ランダムに落とし続けたときの目安:

| 指定 | 結果 | 用途 |
|---|---|---|
| 001〜004 | ゲームオーバーまで 93〜323秒 | 通常のプレイに近い |
| 005〜008 | 12〜40秒で終了 | 短い撮影向け |
| 009 | 170秒 | |
| **010・011** | **終わらない** | 社長どうしが消えて盤面が空くため。長回し向け |

### `?debug=1` — 音声の診断

トップ画面に AudioContext の状態・音声セッション・ミュート状態・BGMの稼働状況を表示する。
スマホで音が鳴らないときの切り分け用。

## 実装

### 当たり判定

画像の**透過していない部分（α ≧ 128）の凸包**を当たり判定に使う。

- 輪郭そのままの凹形状にすると、突き出した指や足が引っかかって積み上がりが破綻するため凸包を採用
- 頂点は 20 個まで簡略化して物理演算の負荷を抑えている
- 重心は凸包の重心。画像中心とのズレは `offsetX` / `offsetY` として持ち、描画時に回転させて補正する
- 物理エンジンは Matter.js（`vendor/matter.min.js` に同梱）。剛体として自由に回転する

サイズは画像の実寸ではなく**不透明ピクセルの面積から求めた等価半径**で決める
（元画像の実寸は出世順になっていない。006 は 007 より大きい）。
等価半径は `26 × 1.16^(n-1)` で 26 → 115 px、盤面は 400 × 720。

地面は物理の床の上面と描画の帯（`floorHeight` = 10px）を一致させている。
ずれるとキャラクターが地面に沈んで見える。

### サウンド

BGM も効果音も **Web Audio API で合成**している。音声ファイルは持たない
（外部ファイル不要・`file://` で動く・容量ゼロという方針を維持するため）。

| 音 | 内容 |
|---|---|
| BGM | Cmaj7 → Am7 → Dm7 → G7 の4小節ループ（104 BPM）。ベース＋アルペジオ＋ハイハット |
| 落下 | 320→150Hz の短い下降音 |
| 出世 | ペンタトニック。役職が上がるほど高く、連鎖でさらに上がる |
| 社長どうし | 5音の上昇ファンファーレ |
| ゲームオーバー | 4音の下降音 |

ブラウザ・端末ごとの制約への対応:

- 自動再生制限があるため、**最初の操作を受けてから** AudioContext を作る。
  1回の操作では `running` にならない端末があるので、鳴るまで操作のたびに再試行する
- iOS は Web Audio が着信音スイッチ（マナーモード）で消音されるため、
  `navigator.audioSession.type = 'playback'` を宣言している（Safari 16.4 以降）。
  **マナーモード中でも鳴り、他アプリの音楽再生を止める。**
  それが困る場合は `'ambient'` に変える（代わりにマナーモード中は鳴らない）
- iOS は他アプリへ切り替えて戻ると AudioContext が `suspended` のままになるため、
  `visibilitychange` で明示的に `resume()` する
- タブが非表示の間は BGM を止める
- `AudioContext` が無い環境では全メソッドが空振りし、ゲームは通常どおり動く

ミュート状態は localStorage に保存される。音量は `js/config.js` の `sound`
（`master` / `bgm` / `sfx`）、曲・音色は `js/sound.js` の `PROGRESSION` と各 `play*` メソッド。

### 画面サイズへの対応

スマホで縦スクロールが出ないよう、ビューポートに収める作りにしている。

- 高さは `100dvh`（動的ビューポート）。`100%` / `100vh` だとアドレスバーを含んだ高さになり、
  スマホでは必ず実表示より縦に長くなってスクロールが出る
- `body { overflow: hidden }` でページ自体のスクロールとバウンドを止める
- 下端は `env(safe-area-inset-bottom)` でホームバーを避ける
- 画面下のミニ進化表は狭い画面（幅700px以下）では隠して盤面の高さに回す
- タッチ端末（`pointer: coarse`）では操作説明を1行に畳む
- 盤面は 400:720 の縦長なので、**横向きのスマホでは「縦向きにしてください」を表示**する

`node tools/layout_check.mjs` で端末ごとの収まりを検算できる。

| 端末 | 盤面 | 画面占有 | トップ画面 / 枠 |
|---|---|---|---|
| iPhone SE 375x553 | 247x445 | 53% | 390 / 445 |
| iPhone 14 390x664 | 296x532 | 61% | 469 / 532 |
| iPhone 14 Pro Max 430x745 | 341x613 | 65% | 495 / 613 |
| Pixel 7 412x733 | 339x611 | 69% | 490 / 611 |

```

  game.js         物理・出世・スコア・ゲームオーバー判定
  render.js       Canvas 描画
```

## 開発

### 画像を差し替えたら

`img/001.png` 〜 `011.png` を置き換えて再生成する。

```bash
python3 tools/build_assets.py          # 当たり判定と軽量画像を再生成
python3 tools/build_assets.py --debug  # あわせて tools/debug/ に凸包の焼き込み画像を出力
```

- 8bit の PNG（RGBA / RGB）に対応。**外部ライブラリ不要**（PNG のデコード・エンコードを標準ライブラリで実装）
- アルファチャンネルが無い画像は、外周から近白色をたどって自動で白抜きする
- `js/stages.js` と `img/optimized/` が更新される

### ファビコン

`img/001.png`（インターン）の頭部を正方形に切り出して生成する。

```bash
python3 tools/build_favicon.py
```

- 元画像は 170x247 の縦長なので、そのままでは正方形のファビコンにできない。頭部をクロップして使う
- `apple-touch-icon.png` だけ背景を不透明にする。**iOS はホーム画面アイコンの透過部分を黒く塗る**ため
- **サブパス配信なので `<link>` での明示が必須**。ブラウザが自動で探すのは
  オリジン直下の `game.chozo.net/favicon.ico` で、そこは別プロジェクトの管轄

### 検証

ブラウザ無しで動作を確認できる。

```bash
npm test                     # 下記の3つをまとめて実行
node tools/test.js           # ルールの検証（判定ポリゴン・スコア・ゲームオーバー・抽選・撮影モード）
node tools/dom_test.js       # DOM スタブ上で index.html 一式を実行するスモークテスト
node tools/layout_check.mjs  # 端末ごとのレイアウトの収まりを検算

SEARCH='?p=009' node tools/dom_test.js   # 撮影モードでの通し確認
node tools/simulate.js 5     # ランダムプレイを5回通しで回す
node tools/tune.js           # 盤面サイズ・出現比率を振って難易度を測る
```

見た目の確認（描画と当たり判定の一致）:

```bash
node tools/snapshot.js 140                 # 140個落とした盤面を JSON に書き出す
python3 tools/render_snapshot.py           # tools/debug/board.png に合成
python3 tools/render_snapshot.py --hitbox  # 当たり判定を重ねて出力
```

### 調整の勘所

`js/config.js` の主な値。

| 値 | 効果 |
|---|---|
| `board.height` | 小さくするとゲームが短く・忙しくなる |
| `spawnWeights` | インターンに寄せるほど出世しやすく、ゲームが長くなる |
| `deadlineY` | 大きくすると猶予が減る |
| `physics.restitution` | 上げるとよく跳ねる |
| `dropCooldownMs` | 連続投下の間隔 |

キャラクターのサイズ自体は `tools/build_assets.py` の `BASE_RADIUS` と `GROWTH`
（変更後は再生成が必要）。

## デプロイ

Cloudflare Workers + Static Assets で配信している。

```bash
npm install     # 初回のみ
npm run deploy  # テスト → dist 生成 → wrangler deploy
```

- `npm run build` が `dist/shusse-game/` を組み立てる。
  **元画像 `img/*.png` と `tools/` は配信しない**（配信サイズ 1.27MB / 20ファイル）
- ルートは `game.chozo.net/shusse-game` と `game.chozo.net/shusse-game/*` の2つ。
  スラッシュ無しのURLは Static Assets が 307 で `/shusse-game/` へ転送する
- 全てのパスが相対参照なので、サブパス配信のための書き換えは不要

`game.chozo.net` のトップページ（ゲーム一覧）は別プロジェクトで管理されているため、
そちらへのリンク追加は別途必要。
